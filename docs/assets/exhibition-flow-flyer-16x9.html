Web / Quest / Replay

変身体験の流れ

Webでスーツ成立、Questで変身試験、Replayで体験を残す。
来場者は4桁コードで自分のスーツを呼び出し、VR内で蒸着・装着・記録再生を体験します。
1

Webで
スーツ作成

身長とvariantを選び、展示PC上でヒーロースーツを成立させます。

2

4桁コードで
呼び出し

Webで発行されたコードをQuestへ入力。同じスーツをVR側で読み込みます。

3601
3

Questで
変身試験

音声・トリガー・粒子演出でアーマーを展開。鏡で装着感を確認します。

4

Replayで
体験を保存

変身の結果を記録再生し、体験の証跡として残します。

仕組み

展示PCが中心 Web/APIとQuest viewerをローカルで起動。外部ネットが弱くても動作。
同じコードで同期 Web Forgeの4桁コードをQuestが読み、同一スーツ仕様を再現。
QuestはUSB優先 ADB reverseでQuestから展示PCのlocalhostへ接続。LANは予備経路。
mocopiは任意強化 接続できる時だけ動き連動を追加。不調時は通常変身体験へ戻す。
当日フォールバック: ネット不調でもローカルPCで続行。mocopi不調でもWeb・Quest・Replayの基本体験は止めません。
