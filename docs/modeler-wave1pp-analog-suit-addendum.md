# Modeler Wave 1++ Analog Suit Addendum

Updated: 2026-04-30

この追補は、Webプレビューで見えている「パーツはあるがヒーロースーツに見えない」問題を、モデラーさんへそのまま渡せる設計意図に落とし込むための資料です。ゴールは、VRMの人体表面を基準にした特撮ボディスーツと、その上に装着される硬質外装シェルを成立させることです。

## 基本方針

- VRMは「人体・フィット対象」です。最終的に見せたいのは、VRMの上に成立する変身後スーツです。
- `base_suit_surface` はVRM表面に貼るボディスーツです。単色の肌代替ではなく、特撮スーツの布地、縫い目、発光ライン、パネル線を持つものとして扱います。
- `armor_overlay_parts` はボディスーツの上に装着される硬質パーツです。浮いた箱やアクセサリではなく、人体面に沿って巻き付くシェルとして造形します。
- Nanobananaのテクスチャは、基礎スーツと外装を同じ世界観で統一します。部位ごとに別素材・別色・別作品に見えるものはNGです。
- 検証ツール上でbboxやmetadataが通っても、Web上で「人がスーツを着ている」ように見えなければモデラー確認ではNGとします。

## 参照から得た制作ルール

コスプレ/EVAフォーム制作の知見では、塗装前の段階で「型紙」「曲面化」「分割線」「接触面」が決まっていないと、完成後も装着物に見えません。PopverseのEVAフォーム解説では、フォームは軽く扱いやすい一方、細部や自然な質感は加工で補う必要があると整理されています。InstructablesのEVAフォーム入門でも、体や型を基準にした型紙化とレイヤー化が重要です。

このプロジェクトでは、その考え方を3Dへ置き換えます。

- 先に人体表面へ沿う「内側面」を決める。
- 次に外側の硬質シェル厚みを決める。
- 最後に溝、段差、発光ライン、トッピングスロットを足す。

## 必須図面

次回納品では、モデルファイルだけではなく、以下の確認図を同梱してください。

- 全身 front / side / back / 3Q 図: 基礎スーツ、外装、発光ラインの重なりが見えるもの。
- 側面シルエット図: 背中の厚み、胸の張り出し、腰ベルト、靴底接地が読めるもの。
- 胴体断面図: upper chest、lower ribs、waist、pelvis の4断面。
- 背面ユニット図: scapula pads、spine ridge、rear core、lumbar clasp、side returns。
- 腰ベルト図: front buckle、side clips、back clasp が一周すること。
- ブーツ図: sole plane、toe cap、heel cap、ankle cuff、shin socket、ground footprint。
- 各GLBのローカル原点、+X/+Y/+Z、内側面、外側面、接触面。

## 部位別NGと修正方向

| 部位 | 現状NG | 必要な状態 |
|---|---|---|
| 背面 | 薄い板、背中から離れたシールドに見える | 肩甲骨から腰へ流れるdorsal shell。側面で厚みと返しが読める |
| 腰 | 前方の箱/桶に見える | 骨盤を一周するbelt loop。前後左右の高さが揃い、浮かない |
| ブーツ | 床の板、足から離れた靴底に見える | 足裏接地、つま先、かかと、足首カフ、すね受けが連続 |
| 胸 | 前だけのプレートに見える | 肋骨側へ回り込む胸郭ラップ。肩・背面と線がつながる |
| すね | 単独の板/棒に見える | ブーツへ自然につながる下腿シェル。膝と足首に可動逃げ |
| 肩 | 球や皿が乗っているように見える | 三角筋を包む肩キャップ。胸側/背面側に短い返しを持つ |

## P0モジュールの要求

P0は以下の8部位です。

- `helmet`
- `chest`
- `back`
- `waist`
- `left_shoulder`
- `right_shoulder`
- `left_shin`
- `right_shin`

P0には、最低限以下の情報をsidecar相当のメモまたは納品コメントに含めてください。

- `variant_key`: 同じ親部位内で差し替え可能な種類名。
- `base_motif_link`: 基礎スーツのどの線/色/発光ラインと接続するか。
- `topping_slots`: 後乗せパーツの取り付け可能位置、最大サイズ、干渉条件。
- `vrm_attachment`: 基準骨、offset、rotation。
- `clearance_m`: 人体表面からの想定クリアランス。
- `shell_thickness_target_m`: 外装として読ませるための目標厚み。

## 今回の実装修正

2026-04-30時点で、`back` は実測bbox zが `0.110m` 程度まで薄くなっていたため、Webプレビューでも背面が板に見えていました。`back_main_shell` の巻き角、厚み、front_bulge、spine keel、rear coreを増やし、再生成後は `0.135m` まで回復しています。仕様ターゲット `0.136m` にほぼ一致します。

この修正は最終造形ではなく、モデラー向けの方向指定です。背面は単なるバックパックではなく、肩甲骨、背骨、腰をつなぐ「装着シェル」として作ってください。

## Nanobanana向けテクスチャ方針

テクスチャ生成はNanobananaのみで進めます。

- 基礎スーツは単色禁止。体表面に沿ったパネル線、縫い目、発光ライン、素材差を入れる。
- 外装パーツは基礎スーツから独立した別物にしない。`base_motif_link` を通じて線や色がつながるようにする。
- 明るい特撮ヒーロー方向。黒すぎるSF、泥汚れ、写実戦闘ダメージ、古典甲冑は避ける。
- パーツごとの局所最適ではなく、全身を1体の変身後スーツとして統一する。
