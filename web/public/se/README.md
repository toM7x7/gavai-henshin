# SE(効果音)スロット

ここに音声ファイルを置くと、体験に自動で組み込まれる(コード変更不要):

| ファイル名 | 鳴る場面 | 音量 |
|---|---|---|
| `henshin.mp3` | 変身の瞬間(/mirror・/ar) | 1.0 |
| `deposit.mp3` | 蒸着シーケンス開始(/s ビューア) | 1.0 |
| `click.mp3` | 全ページのボタン/メニュー/カードのクリック | 0.5 |
| `forging-loop.mp3` | 鍛造工程(stage2)の間ループ(鍛冶屋の環境音) — フェードイン/アウト付き | 0.32 |
| `stage1.mp3`〜`stage4.mp3` | 工程が進んだ瞬間の合いの手(1=解釈 2=鍛造 3=格納 4=公示) | 0.6 |

- 形式は mp3 推奨(ブラウザ互換が最も広い)
- **どれも任意**: 置いたファイルだけ鳴り、無いものは無音(エラーにならない)
- ループ素材は先頭と末尾が繋がる(シームレス)音源にすること
